# Templates de prompts para o ChatGPT / gerador de imagens

Substitua os campos `{{...}}` pelos fatos do briefing e pelos arquivos de produto reais. **Usar prompts individualizados** conforme cada imagem. Nunca mencionar depoimentos reais ou resultados financeiros inexistentes.

## A. Mockup principal para landing

"Crie UMA imagem comercial realista e original de um produto digital brasileiro chamado {{NOME}}, pensado para {{PUBLICO}}. Mostre um mockup fiel ao conteúdo real: {{FORMATO_REAL}}, usando as páginas de amostra anexadas como referência de conteúdo. Composição premium, iluminação natural, sombras plausíveis, alta nitidez, paleta {{CORES}}, título correto {{TITULO}}. Fundo claro e limpo. Não inventar arquivos, não colocar marcas de terceiros, não prometer resultados, não criar texto adicional. Proporção 4:5 ou conforme especificado."

## B. Capa do checkout (quadrada)

"Gerar capa quadrada 1:1 limpa para checkout Wiapy. Produto: {{NOME}}. Cor principal {{COR}}. Visual de {{FORMATO_REAL}}, texto mínimo e correto. Boa leitura a 200 pixels, sem selos fictícios, sem personagens/marcas de terceiros, sem ícones extras. Entregar em alta qualidade; posteriormente a imagem será comprimida para <= 1 MB se exigido."

## C. Banner horizontal do checkout

"Gerar banner horizontal elegante para topo de checkout do produto {{NOME}}. Benefício verificável: {{BENEFICIO}}. Destacar confiança pelo produto real, composição equilibrada e compacta, sem preços anteriores inventados, sem contadores falsos, sem depoimentos. Texto legível em mobile. Paleta {{CORES}}."

## D. Criativo 1/10 — formulário base

"Crie APENAS UMA imagem publicitária original para Meta Ads, 1080x1350, português do Brasil correto. Produto digital {{NOME}}, R$ {{PRECO}}, público {{PUBLICO}}, benefício {{BENEFICIO_REAL}}. Ângulo {{ANGULO}}, gancho {{GANCHO}}, composição {{COMPOSICAO}}, prova real {{AMOSTRA_ENTREGAVEL}}. Headline curta muito legível, hierarquia simples, CTA discreto 'Saiba mais'. Evite alegações sem provas, personagens/marcas conhecidos, falsos prints de vendas, depoimentos inventados ou cronômetros falsos. Diferente dos outros criativos; visual realista e profissional."

## E. Revisão do asset

"Avalie a imagem gerada visualmente: compare texto com o produto, ortografia, recorte mobile, fidelidade das amostras, naturalidade, se há promessas não demonstradas. Se falhar, gere nova versão corrigida, sem alterar o escopo real do produto."

1. Dor do público / close do uso

4. Prévia real / mockup com detalhes
5. Benefício prático / antes e depois funcional **sem resultado fabricado**
6. Benefício prático / simplificação
7. Organização / itens incluídos
8. Organização / navegação de arquivos
9. Oferta direta / preço
10. Oferta direta / utilidade imediata
